# 코드에 한국어 주석 달기

## 작업 순서
1. 요청한 파일을 읽는다 (지정이 없으면 app/의 화면 page.tsx 전부)
2. 파일 맨 위에 "이 화면이 하는 일"을 한 줄로 적는다
3. 화면 덩어리(헤더 · 목록 · 버튼 영역)마다 무엇을 보여주는지 한 줄씩 적는다
4. 상태(로딩 · 빈 · 오류)가 바뀌는 곳에 언제 그렇게 되는지 적는다

## 산출물
- 형태: 원래 코드 파일에 주석만 추가
- 끝나면 주석을 단 파일 목록을 보여준다

## 꼭 지킬 것
- 코드 동작은 바꾸지 않는다 (주석 말고는 수정 금지)
- 화면 이름과 문구는 docs/screens.md, docs/PRD.md에 있는 말을 쓴다
- 주석은 한 줄, 쉬운 말로. 모르는 건 "확인 필요"로 남긴다

## 끝났는지 확인 (O/X)
- [ ] 화면 파일마다 맨 위에 하는 일 한 줄이 있다
- [ ] 주석 말고 바뀐 코드가 없다 (git diff로 확인)
